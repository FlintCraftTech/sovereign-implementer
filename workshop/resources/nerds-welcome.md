**Welcome, nerds. 🤓 Read this before installing anything from here.**

This is a running list of my raw development builds ("test rezips"), posted as I make them. Labels: **stable - [caveats]** — I ran it and it held up. **not stable - [problems]** — known failures, listed on the entry. **under testing - use at your own risk** — too new to vouch for either way. Every entry names the commit it was cut from, and attaches a zip where one is offered.

**Got a zip?** Unzip it somewhere you keep things, ask Claude Code to add the extracted folder as a local plugin marketplace and install Throughliner from it, then fully restart the app — plugins load at launch.

**Straight up: these are dangerous.** They're unsoaked snapshots of work in progress — a label describes only what I'd seen when I posted it, and a bad build can write where it shouldn't or mangle the documents Throughliner manages. Keep your projects in git (Throughliner sets this up by default) so anything a bad build does can be rolled back. **The safe route is the beta release**, pinned in the how-to forum — use this channel only if you enjoy the bleeding edge and will tell me what broke.

**When something breaks:** tell Claude right there in your Claude Code chat — it knows the route, and will draft a GitHub issue on the Throughliner repository and post it on your yes (or draft a report for the form to paste, if you don't have the GitHub CLI). Mention the build label you were on. Every report makes the next beta better
